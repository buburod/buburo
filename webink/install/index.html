Install Webink

iPhone & iPad · Mac

Webink is no longer on the App Store. On iPhone and iPad it installs through SideStore; on Mac it is a direct download. Pick your device.

How this works

SideStore installs apps using your own free Apple developer certificate — the same mechanism Xcode uses to put an app on your own device. Apps signed this way expire after 7 days, so SideStore re-signs them for you. You only need a computer for the initial setup; after that, refreshing happens on the iPhone itself.

Nothing is jailbroken, and your Apple ID password goes to Apple through the installer — not to me.

Before you start

What you need

An iPhone or iPadiOS or iPadOS 15.0 or later, with a passcode set.
An Apple AccountYour normal Apple ID. A free one is fine.
Wi-FiRequired for installing and for refreshing later.
A computer, onceWindows 8+ (64-bit), macOS High Sierra+, or a current Linux distribution. Setup only.
Setup

Five steps

Pick the computer you’ll use for the one-time setup. Everything else is identical.

Install LocalDevVPN on the iPhone

Get it from the App Store, open it, and tap Connect. This has to be switched on any time you install, update or refresh an app in SideStore.

LocalDevVPN — App Store

Install iloader on your computer

Download the .dmg from SideStore’s GitHub releases and drag it to Applications.

Windows must be 64-bit. Install iTunes first — from Apple directly or the Microsoft Store — then run the iloader .msi installer.

Install usbmuxd from your package manager first, then take the .deb, .rpm or AppImage build for your distribution.

sudo apt install usbmuxd   # or the dnf / pacman equivalent
iloader — .dmg
iloader — .msi .exe iTunes
iloader — .deb .rpm .AppImage ARM builds

Install SideStore on the iPhone

Connect the iPhone to the computer with a cable. Open iloader, sign in with your Apple Account, select your device, and choose Install SideStore (Stable).

Trust the certificate

On the iPhone, open Settings › General › VPN & Device Management, tap the entry named after your Apple Account under Developer App, and tap Trust.

Settings › General › VPN & Device Management › Trust

Install Webink

Open SideStore, add the Webink source, and install. The cable isn’t needed again.

Afterwards

Keeping it installed

Apps installed this way expire after seven days. Open SideStore, go to My Apps, and tap the day counter next to Webink to refresh it — LocalDevVPN needs to be connected. Do it before the counter reaches zero and you never lose your library.

If you have a paid Apple Developer account, certificates last a year instead of a week and the three-app limit disappears. With a free account, it is every seven days.

If something goes wrong

SideStore changes its tooling from time to time — these steps match the official documentation as of September 2026. The current version always lives at docs.sidestore.io, which also has the troubleshooting and error-code pages.

How this works

The Mac version is a normal .dmg download. Drag it to Applications and it is installed — no account, no VPN, and nothing that expires. Install it once and it keeps working.

The one hurdle is the first launch. Webink is not signed with an Apple Developer certificate, so macOS blocks it once and says the app is “damaged”. It is not damaged — that is the wording macOS uses for any app it cannot verify. Step 3 clears it, once, permanently.

Before you start

What you need

A MacmacOS 10.15 Catalina or later. Apple Silicon and Intel.
Admin accessNeeded once, to allow the app on first launch.
Nothing elseNo Apple ID, no VPN, no refreshing.
Setup

Three steps

Download the .dmg

Open it and drag Webink into the Applications folder, then eject the disk image.

Download Webink for Mac

Open it once — it will be blocked

Double-click Webink in Applications. macOS shows “Webink is damaged and can’t be opened” and offers only to move it to the Bin. Click Cancel. Nothing is wrong with the download; this happens to every app not signed with a paid Apple certificate.

Allow it, once

Open System Settings › Privacy & Security and scroll down. There is a line saying Webink was blocked, with an Open Anyway button. Click it and confirm with your password or Touch ID.

System Settings › Privacy & Security › Open Anyway

If that line is not there, run this in Terminal instead and then open the app normally:

xattr -dr com.apple.quarantine /Applications/Webink.app

Either way you only do this once. After that Webink opens with a normal double-click, like any other app.

Afterwards

Updating

Nothing expires and there is nothing to refresh. When a new version is out, the app tells you — download the new .dmg and replace the one in Applications.

You only have to allow it again if macOS asks, which it usually does not for a version you have already approved.

Why the warning exists

Apple charges an annual fee for the certificate that removes it. Webink is free and not on the App Store, so it ships unsigned rather than passing that cost on. The download comes straight from the project’s own releases page — you can check the source it was built from at any time.
